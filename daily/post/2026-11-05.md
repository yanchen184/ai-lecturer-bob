今天介紹：browser-use，一個讓 AI agent 直接操控瀏覽器的 Python 開源函式庫。

如果你曾想過「讓 AI 幫我打開瀏覽器、點進網頁、抓資料、填表單」，browser-use 就是做這件事的。它底層走 Playwright，讓你直接把 LLM 接上瀏覽器——不是截圖分析那種，而是真的能操作 DOM、跳頁、點按鈕。

最關鍵的是它的 **Stealth Browser**：針對那些會擋 headless browser 的網站，Browser Use Cloud 提供的 stealth 瀏覽器可以更貼近真實使用者行為，大幅降低被封鎖的機率。

它還有一個 **Hosted Agent API**，不想自己架的話，可以直接呼叫雲端版的 hosted agent API，把需要瀏覽器的任務丟過去就好。另外它也支援 MCP（Model Context Protocol），如果你在用 Claude Code 或其他支援 MCP 的工具，可以把 browser-use 接進去讓 AI 直接開瀏覽器。

安裝也很簡單：`pip install browser-use`，接上你的 LLM API key 就能跑。不過記得「使用前確認目標網站 TOS 是否允許自動化操作」，合規才是長久之道。
