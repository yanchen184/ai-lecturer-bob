今天介紹：onyx，一個開源的 AI 聊天平台，支援市面上所有主流 LLM。

它解決的核心問題是：你不想被單一 AI 服務綁死，但又不想自己從頭架一套前端。如果你有多個 API key（OpenAI、Anthropic、Gemini...）卻還在分頁切換，那這個就是為你設計的。

最關鍵的是**統一介面**：所有 LLM 在同一個 UI 裡操作，支援企業搜尋整合。不用再裝三個 app 才能比較不同模型的回答。
它還具備**開源可自部署**的特性，資料留在自己手上，不用擔心聊天紀錄被第三方收走。
