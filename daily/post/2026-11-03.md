這個跟你最近「ai」主題的讀者很對胃口。

今天介紹：rea，一個用 AI agents 做逆向工程的工具。

傳統逆向工程需要大量人工分析，從 app 行為到底層原生二進制，每個細節都要花時間。rea 的定位是讓 agents 幫你做這件事，從應用程式的行為層一路分析到 native binaries。如果你在做安全研究、漏洞分析或只是想理解某個 app 在底層做什麼，這個工具值得看看。

最關鍵的是用 agents 自動化分析流程：不是你一行一行看 disassembly，而是讓 agent 先跑一遍、給你摘要和結論。
它還具備 Claude Code 整合，也就是說可以在 CLI 環境直接操作，少了 GUI 的額外步驟。

用 TypeScript 寫的，目前有 422k+ stars，算是近期很熱的 AI 工具。安裝方面看 repo 的 README 就好，CLI 流程。不過記得「逆向工程仍有法律灰色地帶，確認使用場景合法再下手」。

👉 GitHub: https://github.com/morluto/rea
