今天介紹：ECC（affaan-m/ECC），一個專為 Claude Code、Codex、Cursor 打造的 Agent Harness 效能優化系統。

如果你在用 Claude Code 寫程式，覺得它每次開新對話就像失憶一樣，什麼都要重新說一遍——ECC 就是來解決這件事的。

最關鍵的是它的 **Skills + Instincts 機制**：讓 AI agent 能帶著技能和行為習慣跑，而不是空手上陣。加上內建的 **Memory**，跨對話的上下文不再每次歸零。

Security 也是 ECC 的設計重點之一，採用 research-first 的開發哲學——安全性從設計階段就納入，不是等出問題再補。

它支援 Claude Code、Codex、Opencode、Cursor 等主流 AI 編碼工具，理論上你現在用的工具就能接上去。

用法直接看 repo README，這個工具迭代速度很快，安裝前記得「先確認最新版本的相容性」。
