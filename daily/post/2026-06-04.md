今天介紹：Dify（langgenius/dify），一個 Production-ready 的 Agentic Workflow 開發平台。

它解決的是這個痛點：你想把 LLM 能力整合進真實產品，但光靠 prompt 疊在一起很快就失控。Dify 把整個 Agentic Workflow 的設計、執行、監控包成一個平台，讓開發者不用從零搭架子。

最關鍵的是 **Agentic Workflow**：你可以視覺化地設計多步驟 Agent 流程，串接各種 LLM 節點、工具呼叫、條件判斷，整個流程可以直接跑在 production 環境，不是只是 demo 用的玩具。

它還具備 **Production-ready 的設計**，有 143k+ star 的社群規模，代表已有大量真實部署案例在背書。主要語言是 TypeScript，跨語言整合方便。

安裝可以 Docker Compose 一鍵起服務，不用自己搭 backend。不過記得「先確認 LLM provider 的 API key 額度，Agentic flow 跑起來消耗不小」。
