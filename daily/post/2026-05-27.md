今天介紹：claude-mem，一個讓 AI Agent 在跨 session 之間保有持久記憶的工具。

你有沒有遇過這個狀況：同一個問題問了 Claude Code 三次，因為每次開新 session 它就什麼都不記得了。這不是 LLM 的問題，是架構的問題——每次對話都是全新的空白。claude-mem 就是來解決這個的。

它的核心邏輯是這樣：每次 Agent session 結束後，claude-mem 會自動捕捉這次 session 做了哪些事、碰到什麼問題、用了哪些工具，然後用 AI 壓縮成精簡的 context 記錄。下次開新 session 的時候，把這份記錄注入回去，Agent 就能「想起來」上次做到哪。

最關鍵的是跨工具相容性：不只 Claude Code，Codex、Gemini、Copilot、OpenCode 都能用，共用同一套記憶庫。如果你同時在多個 AI 工具之間切換工作，這個特性很省心。

安裝方式看 repo 的說明，TypeScript 寫的，照步驟來。不過記得「這是幫 Agent 記憶的工具，不是幫你備份對話紀錄的」，使用前先確認你的工作流程是否真的需要跨 session 上下文。
