今天介紹：Repomix（26,012 ⭐），一個把整個 repo 打包成單一 AI-friendly 文件的工具。

想讓 Claude 或 ChatGPT 幫你分析整個 codebase？不用再一個個複製貼上——Repomix 一鍵把你的 repo 結構化整理成 LLM 看得懂的格式。

最關鍵的是它支援的模型範圍：Claude、ChatGPT、DeepSeek、Gemini、Llama 都吃，哪家 AI 都能用。

用 npx 就能跑，不用全局安裝。不過記得「要先建 .repomixignore 把 node_modules 排掉」，不然 token 燒很快。

👉 GitHub: https://github.com/yamadashy/repomix
