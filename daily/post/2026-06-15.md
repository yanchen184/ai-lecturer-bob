今天介紹：headroom，一個專門幫你壓縮 LLM 輸入的工具。

用過 Claude Code 或 RAG 的人都知道這個痛點：工具輸出太長、log 太多、文件塞一堆，token 超標，費用跟著爆。headroom 就是為了解決這個而生的。

它能壓縮 tool outputs、logs、檔案內容和 RAG chunks，在送進 LLM 之前先瘦身。根據 desc 標榜可減少 60–95% 的 token，而且答案品質幾乎不變。如果你在跑 agentic workflow 或需要塞大量 context，這個可以直接替你砍成本。

最關鍵的是它的彈性：headroom 同時提供三種接入方式——Python library（直接 import 引入）、proxy（不改原有程式碼）、以及 MCP server。Claude Code 用戶可以直接掛上 MCP server，不需要動架構。

安裝也很簡單，`pip install headroom` 就搞定。不過記得「先驗一下壓縮後輸出的正確性，不同任務的壓縮率差距很大」。
