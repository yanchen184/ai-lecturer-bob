今天介紹：ragflow，一個開源的 RAG（Retrieval-Augmented Generation）引擎。

它把 RAG 技術和 Agent 能力融合在一起，為 LLM 打造更好的上下文層。如果你在做 AI 問答系統或知識庫應用，RAGFlow 要解決的就是「讓 LLM 真的讀到對的資料」這個核心問題。

最關鍵的是它的 RAG 結合 Agent 架構：不只是單純的向量搜尋，而是把檢索過程也 agent 化，讓系統能更靈活地判斷該取哪些片段來回答。
它還具備 context layer 的角色定位，把底層的文件管理、分塊、檢索統一在一個引擎裡，不用自己東拼西湊。

專案目前 82,045 ⭐，用 Python 寫的，可以直接跑起來。不過記得「RAG 的品質很大程度取決於你怎麼切分文件，不要直接上 production 前多測幾種 chunk strategy」。

👉 GitHub: https://github.com/infiniflow/ragflow
