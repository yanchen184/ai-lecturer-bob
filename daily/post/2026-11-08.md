今天介紹：ECC，一個 AI 開發者的 agent harness 效能優化系統。

如果你每天都在用 Claude Code、Codex 或 Cursor 寫程式，這個工具就是為你設計的。它把「agent 要怎麼運作」這件事系統化——不只是丟一個 prompt，而是有 Skills（技能管理）、Memory（記憶系統）、Security（安全控制）和 Research-first（研究優先）的完整開發框架。

最關鍵的是它同時支援多個 AI coding 平台：Claude Code、Codex、Opencode、Cursor 全包了。你不用為每個平台各寫一套設定，管理成本大幅降低。

它還強調 security 跟 research-first 開發——不只是「讓 agent 跑起來」，而是讓它跑得穩、跑得可信。這對需要在工作環境部署 AI agent 的開發者來說很重要。

安裝直接 clone GitHub repo 就能開始。不過記得「先看 README 再動手」，框架的設定邏輯跟一般工具不太一樣。
