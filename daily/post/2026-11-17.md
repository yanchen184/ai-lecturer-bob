今天介紹：rea（morluto/rea），一個以 AI Agent 驅動的逆向工程工具。

如果你曾經需要分析不知道從哪來的 app、或者想搞清楚某個二進位程式到底在做什麼——rea 就是為這種場景設計的。它用 Agent 的方式，讓你可以從 app 行為層級一路往下挖到 native binary。

最關鍵的是 **Agent 驅動分析**：不是傳統那種你自己一步一步下工具、自己解讀輸出，而是讓 agent 幫你自動做跨層次的推理。從 app 行為、到 API 呼叫、到底層二進位，它會串起來。

它還支援 Android 平台，而且以 CLI 的方式運行，沒有什麼複雜的 GUI 要裝，直接跑指令就好。

TypeScript 寫的，現在已有 46 萬顆星——相當罕見，代表社群關注度極高。

不過記得「逆向工程前確認你有合法授權分析那個目標」，這工具功能很強，使用場景需要你自己判斷合規性。
