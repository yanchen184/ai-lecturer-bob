今天介紹：huggingface/transformers，一個專門定義最新機器學習模型架構的框架。

你有沒有想過，為什麼同樣是 LLM，不同模型之間切換這麼麻煩？Transformers 就是來解決這個問題的。它把文字、視覺、音訊、多模態模型統一在一個介面底下，不管你是要做推論還是訓練，都用同一套工具搞定。

最關鍵的是統一的模型定義介面：目前支援包含 DeepSeek、Gemma、GLM 在內的大量最新模型，換模型不需要換工具鏈，直接換個 model name 就好。它還具備完整的多模態支援，文字理解、圖片辨識、音訊處理全在同一個框架裡，省去跨套件整合的麻煩。

安裝很簡單，`pip install transformers` 就能開始。不過記得「模型下載會消耗大量磁碟空間，生產環境記得設定 cache 路徑」。
