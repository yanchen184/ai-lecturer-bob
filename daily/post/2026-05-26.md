今天介紹：browser-use，一個讓 AI agent 直接操控瀏覽器完成任務的開源工具。

如果你在試著讓 LLM 幫你執行真正的線上操作——填表單、查資料、點按鈕——就會知道「AI 能看懂網頁」跟「AI 能用網頁」根本是兩回事。browser-use 在中間搭了一座橋：它讓網站對 AI agent 可讀可用，讓 agent 真的能在線上完成任務，而不只是生成一段「你可以去點這個按鈕」的文字。

最關鍵的是它的定位——Make websites accessible for AI agents. Automate tasks online with ease.。它不是一個 chatbot 包裝，而是針對 automation 場景設計的工具層，給 agent 一個可以實際操作瀏覽器的介面。

它還搭配 LLM 後端使用，支援 Python，目前 GitHub 上已累積超過 95k star，在 AI agent 工具圈算是實戰檢驗過的選擇。

安裝很直接，用 pip 安裝後搭配你的 LLM API key 就能跑起來。不過記得「瀏覽器自動化容易踩到反爬蟲機制」，上線前先在測試環境跑過。

👉 GitHub: https://github.com/browser-use/browser-use
