今天介紹：fastmcp，用 Python 快速打造 MCP Server 與 Client 的框架。

在 Claude Code 開發時，想讓 AI 呼叫外部 API，就得建 MCP Server。從零開始要手刻 JSON schema 和通訊協定，很花時間。

fastmcp 解決這個痛點：幾行程式就能把 Python 函式變成 MCP tool，同時支援 Server 和 Client 兩端，開發完可直接測試，不用換工具。

安裝就 `pip install fastmcp`。記得部署時 MCP Server 要放在 Claude CLI 能連到的位置。
