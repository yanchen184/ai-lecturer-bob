今天介紹：headroom，一個在資料進 LLM 之前先壓縮的工具。

如果你在跑 AI coding agent 或 RAG pipeline，token 成本是個痛點。每次呼叫都帶著一堆 tool output、log、JSON 進去，context window 爆掉不說，費用也跑掉了。headroom 就是插在中間的那一層，把這些內容先壓縮，再送給 LLM。

最關鍵的是壓縮效果：coding agent 場景少 20% token，JSON 格式最高可以砍掉 60–95%，而且答案品質不變。這個數字是它的 desc 直接寫出來的，不是我猜的。

它的部署方式很靈活：可以當 library 嵌入程式碼、當 proxy 插在你現有的呼叫鏈上，或者開 MCP server 給 Claude Code / Cursor 這類工具接。如果你本來就在跑 MCP 生態，它可以無縫整合進去。

安裝方式就 pip install headroom，根據你的場景選 library / proxy / MCP server 模式接上去。記得先跑小 batch 確認壓縮後的回答品質符合你的需求，再全面上線。
