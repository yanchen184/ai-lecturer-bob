今天介紹：claude-mem，一個讓 AI Agent 跨 session 擁有持久記憶的工具。

開發 AI Agent 最痛苦的問題之一，就是每次開新 session，之前的上下文全部消失。你教過的東西、跑過的流程、踩過的坑——全部歸零。如果你在用 Claude Code 做複雜的多步驟開發任務，這個問題你一定遇過。

claude-mem 的核心做法是：每次 session 結束後，自動把 Agent 做過的事情壓縮成精簡的記憶，下次 session 開始前再把相關的上下文注回去。它底層用了 embeddings + RAG 技術來做語意檢索，不是單純塞全部歷史，而是找出「這次最相關的記憶」注入。

它支援的工具範圍很廣：Claude Code、Codex、Gemini、Hermes、Copilot、OpenCode 都有支援，不用擔心被鎖死在單一生態。

技術棧是 TypeScript，底層可以用 SQLite 或 ChromaDB 存記憶，也整合了 mem0 跟 OpenMemory 的標準。記得先看 README 確認你的 Agent 環境有沒有支援的 hook 點，不是插上就能跑的。
