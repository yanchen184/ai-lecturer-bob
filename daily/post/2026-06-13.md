今天介紹：headroom，一個專門壓縮 LLM 輸入的工具。

做 RAG 或使用 AI Agent 最常遇到的問題就是：context window 一下子就滿了。工具回傳的 logs、文件片段、搜尋結果，動輒幾千 token，根本沒地方放真正重要的內容。如果你正在用 Claude Code、Cursor，或自己搭 MCP server，這個問題你一定碰過。

最關鍵的是壓縮效果：headroom 聲稱能把工具輸出、logs、RAG chunks 壓縮到只剩 5%-40% 的 token，而且答案品質不掉。這不是截斷，是語意壓縮——把重複、廢話、格式噪音去掉，保留對 LLM 真正有用的部分。

它還同時提供三種使用方式：作為 Python library 直接插進你的程式碼、當 proxy 接在現有 API 前面、或當 MCP server 直接讓 Claude Code 之類的工具調用。對已經有現成架構的人來說，proxy 模式幾乎不用改任何程式。

安裝很直接，`pip install headroom` 就能開始。不過記得「壓縮是有損的，重要的精確資料（數字、日期、程式碼片段）要特別確認壓縮後有沒有失真」。

目前 24,000+ stars，Apache 2.0，算是市場給的一個明確認可。
