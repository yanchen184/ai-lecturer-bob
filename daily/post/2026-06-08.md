今天介紹：n8n，一個 Fair-code 授權的工作流自動化平台，內建原生 AI 能力。

你有沒有遇過這種場景：流程複雜到用 Zapier 做不完，但又不想花時間從頭寫一整套串接程式？n8n 就是為這種情況設計的。它讓你用可視化拖拉的方式建工作流，在需要客製的地方直接嵌入自訂程式碼，視覺操作跟寫 code 可以混著用。

最關鍵的是它有 400+ 內建整合：Slack、GitHub、Google Sheets、各種資料庫，還有各類 AI 服務都有對應的 node，通常不需要自己刻 API 呼叫。

它還同時支援自托管跟雲端版本。自己架的話資料留在自己這邊，對資料敏感的企業場景比較友善。

不過有一點要注意：n8n 是 Fair-code 授權，原始碼公開可看、可改，但商業用途有使用限制，正式用於公司產品前記得確認你的場景是否符合授權規定。
