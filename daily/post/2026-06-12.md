今天介紹：deer-flow，一個 ByteDance 開源的長程 SuperAgent 框架。

你有沒有碰過這種情況：任務太複雜，需要先調查資料、再寫程式、再整合輸出——光靠一個 prompt 來回根本跑不完。deer-flow 就是為這種場景生的。

最關鍵的是它的**長程任務執行**能力：不是跑幾秒就結束，而是能處理需要數分鐘到數小時的複雜任務，讓 Agent 自動串起「研究 → 編碼 → 創作」這整條流程。

它還具備完整的多 Agent 架構——透過 sandboxes（沙盒環境）、memories（記憶體）、subagents（子代理）跟 message gateway 協同運作，不同等級的任務分派給對應的子代理，不會全塞在同一個上下文裡互相干擾。

目前 GitHub 上已有 70k+ star，是 Python 生態裡 SuperAgent 框架裡少數真的能處理長時間任務的選項。如果你在做 deep research 自動化、或是想讓 AI 代理長時間獨立運作，值得試試看。
