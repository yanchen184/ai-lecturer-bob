今天介紹：dify，一個讓你從原型直衝生產環境的 AI 應用開發平台。

它解決了一個很實際的痛點：你辛苦做好的 AI demo，要正式上線就要重寫一遍。如果你正在搭 RAG pipeline 或 Agentic workflow，又希望能在雲端、私有 VPC 或自架環境都跑得起來，這個就是為你設計的。

最關鍵的是協作工作區這個設計：整個團隊可以在同一個空間裡迭代 prompt、接不同 AI 模型（OpenAI、Anthropic、本地模型都支援）、管理工具呼叫，不用每個人各跑各的環境。

它還具備豐富的模型與工具整合支援，RAG pipeline 的設定也在 UI 上就能完成，不用一直寫程式碼黏合各 SDK。對想快速驗證想法又不想被部署細節卡住的工程師來說，省下的時間很可觀。

dify 目前在 GitHub 上累積了 160k+ star，專案還在活躍開發中。
