今天介紹：headroom，一個專門壓縮 LLM 輸入 token 的開源工具。

用過 Claude Code 或搭過 RAG 的人都知道，工具輸出、log 檔、文件片段丟給 LLM 之前那個量有多嚇人——token 爆了不是費用的問題，是整個 context 滿了、模型開始忘東忘西的問題。headroom 就是針對這個痛點設計的：在資料進 LLM 之前先壓縮，官方數字是省了 20% token，同時不犧牲語義。

最關鍵的是**壓縮的不是你的文件，而是 LLM 收到的表示（representation）**：它不是簡單截斷，而是把工具輸出、log chunk、RAG 結果做語義層面的精簡，讓模型看到的資訊更乾淨。如果你的 agent pipeline 常跑到 context limit，或者每個月 API 費用讓你看帳單臉色難看，這個就是為你設計的。

它還具備對 RAG chunks 的壓縮支援，把文件片段在送進 retrieval pipeline 之前就瘦身，查詢速度也跟著起來。

安裝是標準 Python 流程，`pip install headroom` 就能跑起來。不過記得「壓縮換的是效率，邊緣細節資訊有機率被修剪」，對精確度要求極高的場景（比如程式碼 diff、數字報表）要自己評估一下 tradeoff。
