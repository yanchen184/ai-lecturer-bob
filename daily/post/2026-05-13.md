今天介紹：Langflow，一個用來建構和部署 AI agent 與工作流程的工具。

如果你在跑 AI 相關專案，常遇到的問題是：想把多個 LLM 組合起來完成複雜任務，卻不知道從哪下手。Langflow 就是專門解決這件事的，讓你可以組裝 agent 和 workflow，完成從單一 LLM 到多 agent 協作的各種任務。

最關鍵的是它同時支援 agent 和 workflow 兩種模式：agent 模式讓 AI 自主決策下一步，workflow 模式則是固定流程照著跑。兩種模式可以依需求搭配，不會被強迫走某一個路線。

它還具備多 agent（multiagent）支援，意思是你可以讓多個 AI 角色分工，彼此配合完成任務——這在需要拆解工作的複雜應用上很有用。
