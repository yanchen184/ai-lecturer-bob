今天介紹：browser-use，一個讓 AI 直接操控瀏覽器的 Python 開源工具。

以前讓 AI 自動化瀏覽器，要自己寫 Selenium、Playwright 腳本，debug 一堆 CSS selector，還得維護脆弱的定位邏輯。browser-use 把這件事翻過來：你只要告訴 AI「幫我搜尋這個」「填這張表」「截這頁截圖」，底層怎麼點、怎麼等、怎麼處理動態頁面，全部由 AI agent 自己搞定。

最關鍵的是它的 Browser Agent 架構：agent 能看到頁面的可互動元素，決定下一步動作（點擊、輸入、捲動），然後執行，整個迴圈不需要人介入。這讓它可以應付登入流程、多步驟表單、甚至動態 SPA 頁面，不只是靜態頁面抓取。

它還提供 Browser Use Cloud，如果你不想自己架 Chromium 環境，直接走雲端，官方稱之為「stealthy」——就是通過 bot 偵測這件事。

Python 安裝只要：

```bash
pip install browser-use
```

不過記得「瀏覽器自動化走的是你的真實瀏覽器，登入 session 也是你的，跑前確認 scope 和權限」。

👉 GitHub: https://github.com/browser-use/browser-use
