今天介紹：n8n，一個 fair-code 授權的 AI 原生工作流程自動化平台。

它解決的核心痛點是：很多 AI 應用需要串接多個服務，但每次都要自己寫串接程式碼，改起來費時費力。n8n 讓你用視覺化拖拉的方式組合工作流，同時支援自行寫程式碼做客製化邏輯，兩者可以混搭。

最關鍵的是**內建 AI 節點**：直接把 LLM 呼叫、文本處理、資料轉換接進流程裡，不需要自己寫 API 串接的樣板程式碼。

它還具備**400+ 整合**，常見的 SaaS 工具、資料庫、Webhook 基本都覆蓋了，自動化流程可以跑在自架伺服器或雲端，資料不強制出境。

部署也直接，Docker 跑起來就能用：`docker run -it --rm --name n8n -p 5678:5678 docker.n8n.io/n8nio/n8n`。不過記得「fair-code 授權不等於 MIT，商業使用前先看清楚授權條款」。
