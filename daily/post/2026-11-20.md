今天介紹：rea，一個用 AI agent 做逆向工程的 CLI 工具。

它能把任何 app 的執行行為一路拆解到底層 native binary，整個過程由 agent 自動推進。如果你在做 Android 安全分析、或是需要搞清楚某個黑盒子 app 實際行為，這個就是為你設計的。

最關鍵的是用 agent 驅動分析流程：不再需要手動一層一層翻 binary。
它還具備 CLI 介面，TypeScript 實作，直接整合進現有工作流程。

安裝直接 clone GitHub repo 即可。不過記得「逆向工程請在合法授權範圍內使用」。

👉 GitHub: https://github.com/morluto/rea
