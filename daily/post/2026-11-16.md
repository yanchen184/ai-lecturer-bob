今天介紹：headroom，一個專門壓縮 LLM 輸入 token 的工具。

你有沒有遇過這種情況：coding agent 呼叫了一大堆工具、吐出一堆 JSON logs，結果 context window 撐不住，或者 token 費用直接爆掉？headroom 就是為了解決這個問題設計的。

它幫你在資料送進 LLM 之前先壓縮——工具輸出、log 檔、RAG chunk、一般檔案都支援。根據 desc 寫的數字：coding agent 場景可以省下 20% token，JSON 格式最高可以省 60–95%，而且答案品質不變。

最關鍵的是它同時提供三種用法：
- **Library**：直接在你的 Python 程式碼裡用
- **Proxy**：架在你的 LLM API 請求前面自動攔截壓縮
- **MCP server**：接進 Claude Code 或任何 MCP 相容的環境

如果你平常在用 Claude Code 寫程式、跑 agent，或者在搭 RAG pipeline，token 壓縮這件事直接影響到你的速度跟成本。MCP server 模式代表你不需要改任何程式碼，掛上去就能用。
