今天介紹：rea，一個用 AI agent 驅動的逆向工程工具。

它能做的事很明確：從應用程式行為一路分析到原生二進位檔。如果你需要搞清楚某個黑盒程式在幹嘛、或者想快速理解一段 binary 的邏輯，這個工具就是為這個場景設計的。

最關鍵的是它把逆向流程 agent 化了：不是讓你手動一步一步跑 disassembler，而是讓 agent 自動拆解行為鏈。你描述想知道什麼，它幫你追蹤執行路徑。

它還具備 CLI 介面，整合在終端機工作流裡很自然，不用切換 GUI 工具。topics 裡有 `claude-code`，代表它本來就考慮跟 Claude 工具鏈一起用的場景。

目前 GitHub 上已有近 40 萬顆星，活躍程度很高，主要語言是 TypeScript。

安裝也很簡單，參考 repo 的 README 跑起來。不過記得「逆向工程本身的合法性取決於目標軟體的授權條款」，商業軟體請先確認 license。

👉 GitHub: https://github.com/morluto/rea
