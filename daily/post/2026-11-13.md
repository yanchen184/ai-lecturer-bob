今天介紹：rea，一個讓 Agent 幫你做逆向工程的工具。

它的核心定位是：Reverse engineer anything with agents, from app behavior down to native binaries.

如果你在做 App 行為分析、安全研究、或需要深入了解 Native Binary，這個工具就是為你設計的——讓 AI Agent 替你跑逆向流程，而不是靠你自己一行行手動分析。

有幾個關鍵點值得注意：
它用 TypeScript 寫的，有 CLI 介面（topics 裡有 cli），支援 Android 平台（topics 裡有 android），而且跟 Claude Code 有直接整合（topics: claude-code）。

照 GitHub 文件安裝，步驟不複雜。不過記得「逆向工程有法律邊界，只對你有合法授權的目標使用」。

👉 GitHub: https://github.com/morluto/rea
