今天介紹：rea，一個讓 AI agent 幫你逆向分析任何東西的 CLI 工具。

你有沒有遇過這種狀況：手上有一支不熟的 binary，或者一個沒文件的 app，想搞清楚它在幹嘛，卻只能用 IDA/Ghidra 硬啃？rea 想解決的就是這個。

最關鍵的是它走的是 agent 架構：不是只跑一個 prompt，而是讓 agent 持續追蹤 app 行為，從高階應用層一路往下推到 native binary。你不用手動決定每一步怎麼分析，讓 agent 去兜。

它還有 Claude Code 整合（topics 裡看得到 claude-code、agent-skills），代表能接進你現有的 AI 工程工作流，不是孤立的黑盒子。

安裝是標準的 npm/npx 路線（TypeScript 專案）。不過記得「逆向分析的準確度還是要靠你自己驗證，agent 給的結論只是起點」。

👉 GitHub: https://github.com/morluto/rea
