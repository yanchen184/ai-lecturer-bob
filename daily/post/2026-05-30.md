今天介紹：**langflow**，一個讓你用視覺化拖拉方式打造 AI Agent 和工作流程的開源平台。

很多工程師寫 AI 應用時卡在：要把 LLM、向量資料庫、API 串在一起，光是接線就搞半天。Langflow 把這些元件包成積木，用瀏覽器拖拉就能組出完整的多智能體工作流。如果你在搭 RAG pipeline 或 AI chatbot，但不想從頭手寫串接邏輯，這個就是為你設計的。

最關鍵的是**可視化設計器**：每個節點（LLM、memory、tool、API）都能直接在畫布上連接，所見即所得，改一個節點不用重寫整個流程。
它還具備**一鍵部署 API**，流程設計好就能直接轉成可呼叫的 REST endpoint，省掉額外包裝的工。

目前在 GitHub 上有 148,881 顆星，主要用 Python 寫成。安裝直接 `pip install langflow` 就可以跑本地版。不過記得「流程圖好看不代表 token 費用低」，上 production 前記得評估一下 LLM 呼叫次數。
