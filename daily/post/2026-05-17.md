今天介紹：Open WebUI，一個讓你在本地跑 AI 模型的友善介面。

如果你在自己的機器或伺服器上跑 Ollama，或是想接 OpenAI API，卻不想每次都開終端機敲指令，那 Open WebUI 就是為你設計的。它提供一個乾淨的網頁介面，讓你直接在瀏覽器裡跟各種 LLM 對話。

最關鍵的是它支援多後端：Ollama 在本地跑開源模型、OpenAI API 接雲端模型，兩個可以同時掛著，不用切換環境。

它還具備完整的聊天介面管理功能：多對話視窗、對話記錄、模型切換，用起來跟 ChatGPT 的感覺差不多，但完全在你自己掌控的環境裡跑。整個 stack 用 Python 寫，部署也相對直觀。

GitHub 上已有 13 萬多顆星，社群活躍度相當高。
