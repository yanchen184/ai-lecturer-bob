今天介紹：FastGPT，一個架在 LLM 上的知識庫平台。

如果你有一堆內部文件、FAQ、技術手冊，卻不知道怎麼讓 AI 真的「讀懂」並回答問題——FastGPT 就是為這個痛點設計的。它不只是 API 串接，而是完整的問答系統建構平台。

最關鍵的是 RAG 檢索：FastGPT 內建資料處理與 RAG（Retrieval-Augmented Generation）流程，讓你的文件能被正確切塊、索引、召回，而不是硬塞進 prompt 裡。這是解決「AI 亂掰答案」問題的核心。

它還具備視覺化 AI 工作流編排，不用寫 Python 也能拖拉組合資料來源、LLM 節點、條件分支——做出一套可部署的問答系統。支援 OpenAI、Claude、DeepSeek、Qwen 等主流模型，還有 MCP 整合。

想上手的話，直接 Docker Compose 起一個本地版本就可以開始玩。不過記得「知識庫的品質決定問答品質」，花時間整理原始文件比調參數更有效。
