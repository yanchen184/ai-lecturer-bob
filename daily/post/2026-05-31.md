今天介紹：ECC，一個 Agent harness 效能優化系統，專為 Claude Code、Codex、Opencode、Cursor 打造。

用 AI 開發工具一段時間後，你大概會遇到這些問題：Agent 行為不穩定、記憶每次都斷掉、安全邊界模糊不清。ECC 的解法是把 Agent 的能力拆成四個維度系統化地管理：Skills（技能模組）、Instincts（本能設定）、Memory（記憶系統）、Security（安全控制）。

最關鍵的是 research-first 的設計理念：讓 Agent 在執行任務前先建立知識基礎，而不是邊猜邊做。這對工程類任務的準確性影響相當大。

它橫跨目前主流的 AI 編程工具平台，不綁死單一環境。

要注意的是，ECC 是 harness 層的基礎設施，不是直接開箱即用的 plugin。你需要先理解自己的 Agent 架構，才能真正發揮它的效果。
