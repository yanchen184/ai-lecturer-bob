今天介紹：dify，一個讓你從原型直接走到生產的 AI 應用開發平台。

很多人卡在這個問題：RAG pipeline 建好了、workflow 也跑通了，但一要部署成真正能用的產品，就要重寫一遍。dify 就是為了解決這個問題設計的——它讓你在同一個協作工作區裡把 Agentic workflow、RAG pipeline 跟 AI 模型串起來，直接部署，不用重建。

最關鍵的是**統一工作區**：前端測試、後端邏輯、模型配置都在同一個地方，團隊可以同時協作，不會出現「本地跑好了但上線壞了」的情況。
它還支援**多種部署方式**，雲端、VPC、self-hosted 都行，企業級需求直接對應，不用自己搭 infra。

安裝直接用 Docker Compose 就能跑起來。不過記得「先看清楚你想用的 AI model 是否需要另外設 API key」，不然跑起來沒模型可用。
