今天介紹：ECC，一個 AI agent 效能調校框架。

The agent harness performance optimization system.

如果你整天在用 Claude Code、Codex 或 Cursor，常常覺得工具沒充分發揮，這個就是為你設計的。

最關鍵的是**技能系統（Skills）**：它能把你的操作習慣封裝成可重用的指令，讓 agent 下次直接套用，不用每次重新解釋。
它還具備**記憶管理**，讓 AI 跨對話記住你的偏好與上下文，不再每次從零開始。

另外內建 security 模組，確保 agent 執行過程中不會越界存取資源。

安裝很簡單，clone repo 後按文件設定即可接入現有工作流。不過記得「這套框架的效果取決於你自己整理多少 skills 進去，越投入效益越大」。
