今天介紹：ECC（affaan-m/ECC），一個 AI agent harness 效能優化系統。

它的設計圍繞幾個核心模組：Skills（技能）、Instincts（直覺）、Memory（記憶）、Security（安全），並以 research-first development 作為開發哲學。支援 Claude Code、Codex、Opencode、Cursor 等多個平台。如果你在用任何一個 AI coding 工具，這套系統都嘗試讓 agent 在這些平台上跑得更優。

「research-first development」這個方向值得注意：它把研究步驟拉到執行前，而不是讓 agent 直接就動手。Instincts 跟 Memory 的存在讓整個系統不只是無狀態的指令處理器——agent 有記憶基礎可以參考，有直覺模組可以判斷。Security 直接整合進 harness，而不是事後附加。

目前 GitHub 上累積了 202K+ stars，語言以 JavaScript 為主，支援 Claude Code 以外的 Codex、Opencode、Cursor 等 AI coding 工具，算是跨平台通用的設計。
