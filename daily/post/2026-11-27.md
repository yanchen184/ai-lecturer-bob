今天介紹：browser-use，一個讓 AI agent 直接操控瀏覽器的 Python 開源函式庫。

你有沒有遇過這種情況：想讓 AI 幫你自動填表單、爬資料、或按按鈕，但每次都要自己寫 Selenium/Playwright 腳本，然後還要想辦法把操作結果餵回去給 LLM？browser-use 就是來解決這個痛點的。如果你在做 AI agent 開發，需要讓模型跟真實網頁互動，這個就是為你設計的。

最關鍵的是它的 agent-first 設計：不是把瀏覽器當 tool call 的附件，而是讓 AI 直接拿到頁面結構、截圖、DOM 資訊，自己決定下一步點哪裡、填什麼。這跟傳統 Selenium wrapper 的本質差異很大。

它還有提供 Browser Use Cloud 這個托管方案，不想自己管 Chrome headless 環境的話可以直接用 API 呼叫。本地開發用 pip 裝起來，雲端部署走 API，兩條路都通。

安裝很簡單，`pip install browser-use` 就能跑。不過記得「執行真實瀏覽器操作時要注意 side effect」——AI 操控瀏覽器是雙向的，它能幫你按確認也能幫你按刪除，測試環境要隔離好。
