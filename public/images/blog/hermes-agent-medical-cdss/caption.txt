「這種東西出事誰負責?」

第一版用 ChatGPT API 做血脂治療二級預防 CDSS，3 個月後砍掉重做。

問題不是 LLM 不夠聰明，是它「算錯數還很有自信」「編一個聽起來合理的引用頁碼」「同樣的病人每次給不同答案」。醫師看完一句話就讓我清醒過來。

那一刻我才搞清楚:領域 AI 跟「ChatGPT 包一層」是兩種東西。前者要的不是「夠聰明」，是「可被信任 + 可被審計 + 可被演化」。

第二版改用 Hermes Agent 重寫，因為它預設了我需要的四件事:
1. skill 機制 — LLM 不用每次都把整本指引塞 prompt，token 省 80%
2. sandbox execute_code — 公式預先寫成 Python，LLM 不准自己算
3. MCP server 接 RAG — LLM 自主查文獻，拿真實 chunk 不是編
4. JSONL session trace — 出事可以 replay 整段推理

把四件套接起來 = 每個決策有「skill 定義 → 公式回傳值 → RAG 引用 chunk → LLM 最終 JSON」四段證據鏈。醫師問哪一步，我都答得出來。

寫成完整教學分享給做領域 AI(醫療 / 法務 / 金融 / 工控)的同行 ——
含 8-step pipeline、real round-trip case、踩過的三個坑、Hermes vs LangChain vs AutoGPT vs Claude Code 對比。
